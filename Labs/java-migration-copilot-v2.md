# GitHub Copilot Java App Modernization

### Estimated Duration: 4 Hours 

## 📖 Overview

In this lab, you will modernize **Contoso Ltd.'s** Asset Manager application using **GitHub Copilot App Modernization**. The application currently runs on legacy Java technologies and depends on multiple infrastructure components that are not optimized for modern cloud environments.

Using GitHub Copilot App Modernization, you will perform a **complete end-to-end modernization journey**. You will begin by assessing the application to understand its current architecture, dependencies, and migration readiness. Based on the assessment recommendations, you will upgrade application frameworks, migrate supporting services to Azure-native alternatives, and implement operational improvements required for cloud deployment.

Throughout the lab, **GitHub Copilot** will assist with planning, code generation, infrastructure provisioning, configuration updates, and deployment activities. The modernization process includes migrating the PostgreSQL database to Azure Database for PostgreSQL Flexible Server, replacing AWS S3 with Azure Blob Storage, replacing RabbitMQ with Azure Service Bus, enabling application health monitoring through Spring Boot Actuator, containerizing application components, and deploying the final solution to Azure Kubernetes Service (AKS).

By the end of the lab, the Asset Manager application will be transformed into a modern, containerized, cloud-native solution running on Azure infrastructure.

### Task 4: Execute Core Modernization Tasks  

In this task, you will execute the core application modernization activities identified in the modernization plan generated by GitHub Copilot App Modernization. Rather than executing each migration recommendation separately, you will use GitHub Copilot Agent to implement the primary application code and configuration changes in a single workflow.

The agent will analyze the approved modernization plan and apply the required changes to migrate messaging, storage, and database integrations to Azure-native services. This approach reduces repetitive execution steps while still demonstrating the end-to-end modernization capabilities of GitHub Copilot.

   > **Note:** In this lab, we focus on the core application modernization activities to reduce execution time and improve the learning experience. Infrastructure provisioning, deployment automation, and container deployment activities will be performed in later tasks.

   > In real-world modernization projects, organizations typically execute the complete modernization plan, including infrastructure provisioning, security integrations, deployment pipelines, monitoring, and operational configurations as part of a broader migration strategy.

1. In the Copilot Chat panel, enter the following prompt to execute the modernization plan:

    ```
    Execute the approved modernization plan. 
    
    Implement: 
    - RabbitMQ to Azure Service Bus migration 
    - AWS S3 to Azure Blob Storage migration 
    - PostgreSQL Managed Identity integration 
    
    Do not provision infrastructure. 
    Do not deploy the application. 
    Do not run extensive tests.
    ```

    ![](images/new/T4S1-0106.png)

    > **Note:** When prompted, click on **Allow** to let the agent run and implement the modernization tasks. This process may take approximately 30–40 minutes to complete.

    > **Note:** Do not interrupt while provisioning scripts, migration scripts, or code transformation tasks are running.

### Task 5: Expose health endpoints using Custom Tasks

In this task, you will create and execute a custom GitHub Copilot App Modernization task to expose application health endpoints using Spring Boot Actuator.

Modern cloud platforms continuously monitor deployed applications to determine whether they are healthy and able to serve requests. Platforms such as Azure Kubernetes Service (AKS) and Azure Container Apps use health endpoints to verify that an application has started successfully and remains operational.

GitHub Copilot will use a custom task and reference documentation to analyze the application, add the required Spring Boot Actuator dependencies and configuration, and expose health endpoints that can be used by cloud-hosted environments.

     - **Skill Description:** This skill helps add Spring Boot Actuator health endpoints for Azure Container Apps deployment readiness. **(2)** 
     - **Skill Content:**  You are a Spring Boot developer assistant. Follow the **Spring Boot Actuator documentation** to add basic health endpoints required for Azure Container Apps deployment. **(3)**

### Task 6: Containerize Applications

In this task, you will containerize the application using GitHub Copilot App Modernization.

Containerization packages an application and its dependencies into a portable image that can run consistently across development, testing, and production environments. Containers are a foundational building block for modern cloud-native deployments and Kubernetes-based platforms such as Azure Kubernetes Service (AKS).

GitHub Copilot will analyze the application structure, generate a containerization plan, create Dockerfiles, build container images, and help resolve any build issues encountered during the process.

1. Open the **GITHUB COPILOT MODERNIZATION (1)** from the sidebar menu. In **Tasks** view, expand the **Common Tasks** -> **Containerize Tasks** **(2)** and click on **Run task**  button **(3)** for **Containerize Application** task.
  
    ![Run Containerize Application task](images/new/T6S1-0506.png)

1. When prompted, click **Continue** or **Allow** in chat notifications, or type **y** / **yes** in the terminal as Copilot Agent follows the plan and leverages agent tools to create and run provisioning and deployment scripts, fix potential errors, and complete the deployment.  

   >**Note** : **Do not interrupt** while the provisioning or deployment scripts are running.

1. A predefined prompt will be populated in the **Copilot Chat panel** with **Agent Mode** enabled.  
   Copilot Agent will analyze the workspace and create a file named **containerization-plan.copilotmd** containing the containerization plan.

   ![Containerization prompt and plan](images/new/T6S3-0506.png)

1. View the plan and collaborate with Copilot Agent as it follows the **Execution Steps** in the plan by clicking **Continue**/**Allow** in pop-up chat notifications to run commands. Some of the execution steps leverage agentic tools of **Container Assist**.
    
1. Copilot Agent will help generate Dockerfile, build Docker images, and fix build errors if there are any. Click **Keep** to apply the generated code.

   >**Note**: Please wait while Copilot completes the task, which may take approximately 20–30 minutes.

1. Navigate to the **worker (1)** folder in VS Code and verify that the **Dockerfile (2)** is created.

    ![](images/new/T6S6-0506.png)
